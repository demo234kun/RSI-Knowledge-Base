```
└────────────────────────┬───────────────────────────────────┘
                         ▼
┌────────────────────────────────────────────────────────────┐
│  V 验证器 = 确定性回测引擎（pandas 向量化，免费）            │
│    · 300 成分股 / 3 指数日线（研究0已落地，前复权）           │
│    · 成本模型：T+1、涨跌停、印花税/佣金/滑点（研究0标准）     │

                         ▼

└────────────────────────┬───────────────────────────────────┘
                         ▼
              循环至预算耗尽 / 分数收敛（样本外验证）
```

## 3. TTRL 循环伪代码（MVP 规格）

```python
def ttrl_strategy_loop(market_state, template, budget=200):
    strategies, scores = [], []
    reflection = ""
    for i in range(budget):
        # G：生成（带上轮反思 + 市场状态 + 模板）
        params = llm.generate(market_state, template, reflection, topk=5)
        # V：回测打分（样本内窗口）
        for p in params:
            s = backtest.evaluate(p, window='is')          # 多目标→标量
            strategies.append(p); scores.append(s)
        # U：束筛选 + 反思
        top = select_top_k(strategies, scores, k=10)       # 保最优
        reflection = llm.reflect(top_low.scores)           # 反思低分原因
        strategies = top                                     # 下轮从 Top-K 变异
    # 最终：样本外验证 + Deflated Sharpe
    best = select_best(top)
    return verify_oos(best), walk_forward_report()
```

**关键设计点**：
1. **样本内/样本外严格分离**：循环内只用 IS 窗口打分；最后统一 OOS 验证（一次，不迭代）→ 防"在测试集上进化"。
2. **写保护 holdout**：预留最后 1 年的数据**绝不让循环碰到**（防数据污染，对应 [P01](../论文/cards/P01_RSI综述_2607.07663.md) 安全讨论）。
3. **多目标 + 复杂度惩罚**：夏普为主 + 回撤/换手/复杂度惩罚 → 防规则膨胀（[P10](../论文/cards/P10_算力瓶颈_2507.23181.md) 之外金融特有的过拟合防线）。
4. **复杂度惩罚**：策略长度/参数数进适应度（WPI 03-09 经典结论）。

## 4. 验证协议（防"伪自改进"——金融 RSI 的第一风险）

| 检验 | 工具 | 通过标准 |
|---|---|---|
| 样本外显著性 | Deflated Sharpe Ratio（Bailey & López de Prado）| DSR > 0.95 |
| 过拟合边界 | IS-OOS 保留率（MadEvolve 协议）| ≥ 0.5 |
| 时序稳健性 | 多窗口 walk-forward（每窗口独立循环）| 多数窗口通过 |
| 退化监控 | 逐代独立评测（对应 [P09](../论文/cards/P09_内省阈值_2607.04277.md)）| 无 improvement degradation |
| 对照基线 | 买入持有 / 静态最优参数 / 随机策略分布 | 显著占优（t-stat）|

> **为什么必须做**：TTRL 的回测分数是"自生成的自标签"——若无严格 OOS，系统会学到"怎么骗过 IS 回测"而不是"怎么赚钱"。这就是 [P08](../论文/cards/P08_SelfRewardingTheory_2601.22513.md)"自洽≠正确"在金融的等价形态。

## 6. 风险与对策

| 风险 | 机制 | 对策 |
|---|---|---|
| **过拟合自循环** | LLM 学会"骗回测" | 写保护 holdout + DSR + IS-OOS |
| **策略塌缩**（多样性丧失）| 束搜索太贪心 → 全族趋同 | 表现加权 + 温度 + 低相关多样性项（MAP-Elites 是 B 阶段解）|
| **环境漂移**（regime 变化）| IS 窗口全是牛市 → 熊市失效 | 状态门控：按 regime 匹配训练窗（研究0 ③-a）|
| **反思幻觉**（反思内容是废话）| 低分原因归因错误 | 归因结构化：只允许引用可计算诊断信号（研究0 三维诊断）|
| **退化**（[P09](../论文/cards/P09_内省阈值_2607.04277.md)）| 迭代多轮后分数不再涨 | 每代独立评测 + 超过 N 代无提升即终止并回溯 |
