# 📈 金融应用区 · RSI 方法论 × 金融市场

> **问题**：RSI（递归自我改进）怎么用在金融方向？哪些能做？最小成本复刻方向是什么？
> **结论**（30 秒版）：金融是 RSI 的**最佳实践场**——因为回测引擎是"免费的确定性验证器"，而验证器恰是所有 RSI 回路（GVU）里最贵、最难做对的一环。**最小成本方向 = 复刻 TTRL（测试时强化学习，[P04 LADDER](../论文/cards/P04_LADDER_2503.00735.md)）**：不训练任何模型权重，只用"LLM 生成策略 + 回测打分 + 分数引导重生成"，全套成本 ≈ 数百元（LLM API）+ 已有数据 + 一台开发机。

## 1. 为什么金融适合做 RSI（核心洞察）

RSI 知识库的方法族（[P01](../论文/cards/P01_RSI综述_2607.07663.md) 双轴分类、[P02 GVU](../论文/cards/P02_GVU_2512.02731.md) 统一算子）都可以抽象为：

```
Generator（生成改进） → Verifier（验证改进） → Updater（采纳/学习改进） → 回环
```

| RSI 环节 | 通用 AI 域的痛点 | 金融域的对策 | 结论 |
|---|---|---|---|
| **G 生成器** | 需要新任务/新数据触发 | LLM 按市场状态生成/变异策略代码 | ✅ 直接复用 |
| **V 验证器** | **最难做对**——自建评判器有自洽≠正确风险（[P08](../论文/cards/P08_SelfRewardingTheory_2601.22513.md)） | **确定性回测引擎**：夏普/回撤/超额客观计算，免费、可复现 | ✅✅ **金融的最大优势** |
| **U 更新器** | 需训练（昂贵）或 prompt 层（脆弱） | 种群演化（MAP-Elites）+ 经验记忆库 + 表现加权采样 | ✅ 无训练 |
| **闭环稳定性** | 自递归易退化（[P09](../论文/cards/P09_内省阈值_2607.04277.md)） | walk-forward + Deflated Sharpe + IS-OOS 衰减监控（[P04](../论文/cards/P04_LADDER_2503.00735.md) 协议） | ✅ 有成熟统计工具 |

**一句话**：通用 AI 里"验证"是最贵的一环（要做奖励模型、评判模型、防自洽漂移）；金融里验证=回测=免费。所以金融做 RSI 的**边际成本比通用 AI 低一个量级**。

## 2. RSI 方法族 → 金融应用映射矩阵（哪些能做）

| RSI 方法（卡片） | 金融应用场景 | 技术可行性 | 成本档 | 优先级 |
|---|---|---|---|---|
| **自精修/反思**（[P11](..//论文/cards/P11_ReflectRetryReward_2505.24726.md)） | 策略失灵诊断：反思亏损原因→注入下轮变异 prompt（Reflexion 式） | ★★★★★ | 💰 | 🥇 立即可做 |
| **TTRL 测试时 RL**（[P04 LADDER](..//论文/cards/P04_LADDER_2503.00735.md)） | **策略生成-回测-打分-重生成**，不训练权重 | ★★★★★ | 💰 | 🥇 **最小成本首选** |
| **LLM×演化种群**（AlphaEvolve/MadEvolve 路线） | 策略代码种群 + MAP-Elites 保多样性 + 回测评估器 | ★★★★★ | 💰💰 | 🥇 研究0已有蓝本 |
| **经验记忆库**（Voyager 技能库 × Reflexion） | 失灵案例/市场转换/教训三类记忆沉淀复用 | ★★★★★ | 💰 | 🥇 已在研究0 |
| **内省阈值守卫**（[P09](..//论文/cards/P09_内省阈值_2607.04277.md)） | 退化监控=检查系统是否位于门槛以上（样本外不退化） | ★★★★★ | 💰 | 🥇 免费风控 |
| **NeoHorse 闭环复刻**（[P12](../论文/cards/P12_NeoHorse1_2609.08183.md)） | 复刻"能力反馈→下一轮训练混合"：按表现加权策略采样分布 | ★★★★☆ | 💰💰 | 🥈 结构最优 |
| **自我博弈**（[P05](..//论文/cards/P05_SSR_2512.18552.md)/[P06](..//论文/cards/P06_LSP_2509.07414.md)/[P07](..//论文/cards/P07_TSPIN_2601.08198.md)） | 多空对抗生成压力场景，做回测的压力测试 | ★★★☆☆ | 💰💰💰 | 🥈 中级 |
| **自我奖励/自建评分器**（[P08](..//论文/cards/P08_SelfRewardingTheory_2601.22513.md)） | LLM 自己定义策略质量 | ★★☆☆☆ | 💰💰💰 | ⚠️ 高风险不推荐 |
| **Gödel Agent 自参考重写**（[P03](../论文/cards/P03_GoedelAgent_2410.04444.md)） | 策略引擎改写自身代码 | ★★☆☆☆ | 💰💰💰💰 | ❌ 高成本高破坏 |
| **AI 科学家自动研究**（P01 研究过程类） | 假设生成→回测→自动写研究笔记 | ★★★★☆ | 💰💰 | 🥈 后期 |

> ⚠️ **自我奖励不推荐的理由**（金融特有）：市场不会奖励"自洽"，只奖励样本外表现。用 LLM 自建评分器 = 把免费的确定性验证器（回测）换成昂贵的、会漂移的主观评分器——方向性错误（对照 P08 的自洽≠正确）。

## 6. 学习要点速记（金融服务者速查）

- 金融做 RSI 的本质 = **免费验证器（回测）撑起的三环回路**：生成→回测→采纳。
- **护城河不在模型，在数据 + 验证协议**：谁的 walk-forward/防过拟合/退化监控更严格，谁的"自进化"才是真改进（对照 [P09](../论文/cards/P09_内省阈值_2607.04277.md) 与 [P10](../论文/cards/P10_算力瓶颈_2507.23181.md)）。
- 金融 RSI 的**第一风险**不是"智能爆炸"，是**过拟合**：IS-OOS 保留率 + Deflated Sharpe + 写保护 holdout 是标配。
- 参考行业实践（2025-26）：群益期货"AI 策略生成器"的生成-编译-修正闭环、中信建投"信谛听"NL→回测自证闭环、天弘基金"AI 迭代因子"（70% 超额因子来自 AI 学习且 75% 年内被迭代）——与本文方案同构。
