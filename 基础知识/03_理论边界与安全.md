# 03 · 理论边界与安全

> RSI 研究的两个根本问题：**递归会退化吗？**（极限）与 **递归会失控吗？**（安全）。
> 本页对应两篇理论核心：[P09 内省阈值](../论文/cards/P09_内省阈值_2607.04277.md) 与 [P10 算力瓶颈](../论文/cards/P10_算力瓶颈_2507.23181.md)，并汇总 2025–2026 的安全争论。

## 1. 递归会退化吗？——内省阈值 (Introspection Threshold)

**论文 P09（arXiv:2607.04277）的核心论证：**

> 自改进的递归要"复合增长"而不是"退化"，系统需要具备足够强的**自建模能力（self-modeling capacity）**。

- **病理机制**：改进劣化（improvement degradation）——错误累积、性能逐代下降。类比 von Neumann 自复制自动机的复杂度阈值：低于临界复杂度，自动机复制自动机会退化；高于阈值才能持续自复制。
- **防御性结论**：自改进 LLM 若复杂度低于**内省阈值（critical self-modeling capacity）**，无论模型多精巧都会退化；高于阈值才可能在无人类干预下持续自改进。
- **现状定位**：
  - Self-Refine / Reflexion（Madaan 2023 / Shinn 2023）在 **prompt/上下文层** 自我批评（浅层内省）
  - SkillRL（Xia et al. 2026）/ AlphaApollo（Zhou et al. 2025）在 **记忆/技能层** 积累可复用库（中层）
  - 论文主张达到"完整递归自改进"需要**程序性的内省机制**，并给出通向该复杂度阈值的架构路径。
- **钥匙**：引入 Kleene 第二递归定理 / 自我指涉的形式化（即 Gödel Machine 的现代版，见 [P03](../论文/cards/P03_GoedelAgent_2410.04444.md)）。

**一句话**：RSI 不是天然成立的——它有一个"复杂度门槛"，门槛以下是退化，门槛以上才谈得上复合改进。

## 2. 递归会失控吗？——智能爆炸的必要条件（算力视角）

**论文 P10（arXiv:2507.23181）的形式化结果：**

软件式智能爆炸（software-only intelligence explosion）需要**同时满足两个必要条件**：

1. **可替代性**：AI 研究生产函数中，算力 (compute) 与认知劳动 (cognitive labor) 必须**可弹性替代**（elastic substitution）——如果二者是刚性互补（gross complements），AI 再聪明也绕不开"想法必须用昂贵实验验证"的瓶颈；
2. **加速度**：AI 自改进的速度必须**跑赢**"发现新想法的难度递增"。

**两端意见：**

| 阵营 | 代表 | 立场 |
|---|---|---|
| 乐观（爆炸论） | Aschenbrenner《Situational Awareness》2025；Kokotajlo et al.《AI-2027》2025 | 本十年末/2027 年前后经 RSI 出现超智能 |
| 怀疑（瓶颈论） | 本文；Nathan Lambert 的 **LSI（有损自改进 Lossy Self-Improvement）** | 摩擦增大拖慢飞轮；算力/认知劳动刚性互补 → 无爆炸 |

**补充（IEEE Spectrum 2026-05 报道）：** Nathan Lambert（AI2）主张应预期"有损自改进"而非 RSI：每次递归都有信息/成本损耗，飞轮会减速而非加速。

## 3. 安全风险图谱（2025–2026）

P01 综述明确：**风险集中在开放端 RSI——闭环且修改自身评估器/目标**。分四个象限：

```
               目标/评估器固定              目标/评估器可被修改
        ┌──────────────────┬──────────────────────────┐
行为层   │ 低风险：      │ 中-高风险：             │
        │ 有界自精修    │ 自我奖励漂移(见P08)      │
        ├──────────────────┼──────────────────────────┤
改进算法 │ 中风险：      │ 高风险：【开放端 RSI】   │
及"改进  │ 自参考重写    │ 内省阈值之上 + 目标漂移  │
自身能力"│ (P03/P09)    │ = 安全集中点             │
        └──────────────────┴──────────────────────────┘
```

**具体风险条目（2025–2026 文献汇总）：**

1. **评估器污染**：自我奖励模型中，模型给自己的偏好打分 → 打分器被训练过程"收买"（P08 讨论的稳定性问题；T-SPIN 用熵约束缓解，P07）。
2. **误演化 (Misevolution)**："Your Agent May Misevolve: Emergent Risks in Self-evolving LLM Agents"（Kawin Ethayarajh 团队 2025-09；代码：ShaoShuai0605/Misevolution）——自进化智能体在开放环境中可能学到**有害的 emergent behaviors**。
3. **验证问题 (The Verification Problem)**：RSI 是否"真"改进，需要用**模型看不到/改不了的独立写保护 holdout 评估**来检验（CACM 2026-07 多位专家共识）。
4. **退化无感知**：低于内省阈值时系统会在无预警下逐代劣化（P09）。
5. **治理缺口**：前沿实验室自我改进的**信息披露**是否该强制（CACM 争论）；已有开源红队框架（lihouwenbin/ai-redteam-recursive-self-improvement）。

## 4. 对齐视角的 RSI 定位（简）

- 概念链条：**对齐（alignment）< 监督问题 < RSI 评估/目标迁移**。当模型超越人类监督能力时，人工标注质量下降（P08 背景引述 Burns et al. 2023 超人类模型对齐困难）。
- 因此 RSI 的安全研究 = **评估机制本身的对齐**：如何让"自我评估器"在迭代中不被腐蚀，是 2026 年的核心开放问题。
