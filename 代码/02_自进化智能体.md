# 02 · 自进化智能体（Self-Evolving Agents）

> 这一类是"**智能体在任务中积累经验 → 反哺自身能力**"的自进化路线，对应论文卡片 [P04 LADDER](../论文/cards/P04_LADDER_2503.00735.md)、[P05 SSR](../论文/cards/P05_SSR_2512.18552.md)、[P06 LSP](../论文/cards/P06_LSP_2509.07414.md) 的工程落地。**注意区分**：多数项目属"在固定评估器下的自进化"（半闭环），非开放端 RSI。

## 项目详情

### 1. zhengkid/Dream-RSI ⭐846 · 2026-09 · Python
- **定位**：**Dream-RSI: Recursive Self-Improvement through Evolving Worlds** 官方实现。
- **RSI 关联**：核心思想是在**演化世界中**让智能体经历多样环境，通过"做梦/想象世界"驱动递归自改进——2026 年提出的"环境侧自进化"新机制。
- 链接：https://github.com/zhengkid/Dream-RSI

### 2. TokenRhythm/NeoHorse ⭐625 · 2026-09 · Python
- **定位**：**NeoHorse-1: Towards RSI via Agentic Post-Training with Routing Harness**（技术报告 arXiv:2609.08183，[P12 精读卡片](../论文/cards/P12_NeoHorse1_2609.08183.md)）。TokenRhythm 基元律动出品，华为系作者群。
- **RSI 关联**：用**路由 harness**（异构模型池智能路由）做智能体后训练：真实交互轨迹→结构化训练数据→三阶段课程 SFT+蒸馏→**能力反馈决定下一轮训练混合**（`评估→选择→更新`闭环）。4B 宏平均 58.94→64.87、9B 65.60→69.04。
- **模型发布**：[ModelScope NeoHorse-1-4B](https://www.modelscope.cn/models/TokenRhythm/NeoHorse-1-4B)（≈4B，Qwen3.5-4B 底座，Apache-2.0，BF16，8K→262K 原生上下文可扩至 1M，text-only）· [HuggingFace 合集](https://hf.co/collections/TokenRhythm/neohorse-1) · 网站 [tokenrhythm.ai](https://tokenrhythm.ai)
- **金融复刻价值**：闭环结构（路由→记录→反馈→下一轮混合）可免训练移植到量化研究——详见[金融应用方案](../金融应用/方案_最小成本复刻TTRL.md)的"表现加权采样"设计。
- 链接：https://github.com/TokenRhythm/NeoHorse

### 3. HITsz-TMG/KnowAct ⭐485 · 2026-07 · Python
- **定位**：**RSI 个人助理（Personal Assistant）**——把递归自改进落到个人助理场景。
- **RSI 关联**：日常交互中积累知识 → 改进自身行为；代表"自进化智能体"从研究走向产品化的一支。
- 链接：https://github.com/HITsz-TMG/KnowAct

### 4. AetherLabsAI/RSIAgent ⭐349 · 2026-09 · Python
- **定位**：**免训练（training-free）多智能体 RSI 框架**：广-深自主探索 + 可复用记忆。
- **RSI 关联**：不动权重，通过**记忆复用 + 探索策略改进**实现自进化（与 [P04](..//论文/cards/P04_LADDER_2503.00735.md) 的"无需改参数也能提升"思路同族）。
- 链接：https://github.com/AetherLabsAI/RSIAgent

### 5. KnowledgeXLab/EvolveR ⭐120 · 2025-09 · Python
- **定位**：**EvolveR（ICML 2026）**：通过**经验驱动的生命周期（Experience-Driven Lifecycle）**自进化 LLM 智能体。
- **RSI 关联**：把"经验获取→内化→利用→演化"做成一个生命周期闭环；ICML 2026 顶会论文配套代码。
- 链接：https://github.com/KnowledgeXLab/EvolveR

### 6. Gen-Verse/ScienceBuddy ⭐68 · 2026-09 · Python
- **定位**：**ScienceBuddy：递归-内-递归（Recursive-in-Recursive）自改进的科学交互智能体**。
- **RSI 关联**：交互式科学智能体里的双层递归自改进——外层改进研究流程，内层改进每次交互策略（对应 P01"自动研究"类别）。
- 链接：https://github.com/Gen-Verse/ScienceBuddy

## 阅读提示

- 多数项目仍属"**在固定目标/固定评估器下的自进化**"（半闭环）——它们在赤道上推进 RSI 的工程化，但按 P01 的定义**不是开放端 RSI**。
- 与安全视角配套：自进化智能体可能发生 **Misevolution（误演化）**，见 [03 区](03_基础设施安全与资源.md) 的 ShaoShuai0605/Misevolution。
