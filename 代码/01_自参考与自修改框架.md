# 01 · 自参考与自修改框架（Self-Referential / Self-Modifying）

> 这一类的核心是 **"智能体改进自身的代码/策略/改进算法"**——最接近 RSI 严格定义的"自我指涉"。对应论文卡片 [P03 Gödel Agent](../论文/cards/P03_GoedelAgent_2410.04444.md) 与 [P09 内省阈值](../论文/cards/P09_内省阈值_2607.04277.md)（门槛以下的递归会退化，跑这些框架时注意观测是否退化）。

## 项目详情

### 1. Arvid-pku/Godel_Agent ⭐223 · 2024-10 · Python
- **定位**：Gödel Agent（ACL 2025，P03）**官方实现**——第一个可运行的自我指涉 LLM 智能体框架。
- **RSI 关联**：`π_{t+1}, I_{t+1} = I_t(π_t, I_t, r_t, g)`——策略与**学习算法同时**被递归更新；用 monkey patching 实现运行时自感知/自修改。
- **上手**：官方 repo 提供数学推理与智能体任务样例；可作为"理解自我指涉"的入门代码。
- 链接：https://github.com/Arvid-pku/Godel_Agent（注意：`Godel-Agent`（连字符）会 404，正确写法为下划线 `Godel_Agent`）

### 2. facebookresearch/HyperAgents ⭐2.7k · 2026-03 · Python（Meta AI）
- **定位**：**自我指涉的自改进智能体**，官方口号 "can optimize for any computable task"。
- **RSI 关联**：把"自我指涉"落到"可优化任意可计算任务"的通用性上——智能体能改写自身求解逻辑以优化任意目标；与研究实验室（facebookresearch）配套论文/报告。
- **注意**：2026-07 后 pushedAt 停滞，确认是否为研究发布版。
- 链接：https://github.com/facebookresearch/HyperAgents

### 3. jennyzzt/dgm（Darwin Gödel Machine）⭐2.3k · 2025-05 · Python
- **定位**：**Darwin Gödel Machine：开放式演化（Open-Ended Evolution）的自改进智能体**（论文 arXiv:2505.22954，共一作者 Jenny Zhang、Shengran Hu；Cong Lu / Robert Lange / Jeff Clune）。
- **RSI 关联**：把 Schmidhuber 的 Gödel Machine 与 Darwin 演化结合——不只自我重写，还引入**种群/变异/选择**的开放演化；2025 年 RSI 方法层的代表作之一。
- **注意**：常被误记为 `SakanaAI/Darwin-Godel-Machine`（该组织下无此仓，404）；官方页 [sakana.ai/dgm](https://sakana.ai/dgm)，官方代码即本仓。
- 链接：https://github.com/jennyzzt/dgm

### 4. MaximeRobeyns/self_improving_coding_agent（SICA）⭐401 · 2025-04 · Python
- **定位**：**SICA（Self-Improving Coding Agent）官方实现**——"a coding agent framework, that works on its own codebase"。
- **RSI 关联**：Coding agent 直接**在自身代码库上工作并改进自己**：利用强化学习后训练提升代码改进技能；GSM8K / SWE-bench 验证。（用户提供 `HexoAI/SICA` 链接 404；SICA 论文对应仓库即本仓。）
- 链接：https://github.com/MaximeRobeyns/self_improving_coding_agent

### 5. Continual-Intelligence/SEAL ⭐1.9k · 2025-06 · Python
- **定位**：**SEAL（Self-Adapting Language Models）**：模型参数级的自适配/自修改。
- **RSI 关联**：走**权重层自修改**路线——模型**无需人工标注数据**即可自我编辑/继续学习（含"权重编辑"、LoRA 微调、ReST-EM 数据筛选等机制），把 RSI 推进到"改权重"而非只改代码/策略。
- **门槛**：实测 `import torch` 即遇 GPU 门槛；按官方要求需 2×A100/H100。
- 链接：https://github.com/Continual-Intelligence/SEAL

### 6. ShengranHu/ADAS ⭐1.6k · 2024-07 · Python
- **定位**：**ADAS（Automated Design of Agentic Systems）**，ICLR 2025——用**元 Agent 搜索**自动设计智能体系统。
- **RSI 关联**：把"改进算法"交给 LLM 搜索——元 Agent 编写 `forward()` 代码 → 执行/评测 → 演化出新智能体（DGM 共一作者 Shengran Hu 的前作，与本区 #3 同源）。
- 链接：https://github.com/ShengranHu/ADAS

### 7. SakanaAI/ShinkaEvolve ⭐1.4k · 2025-09 · Python
- **定位**：**ShinkaEvolve**："Towards Open-Ended and Sample-Efficient Program Evolution"（Sakana AI）。
- **RSI 关联**：样本高效 + 开放式**程序演化**——LLM 驱动变异 + bandit 选择；与 Darwin GM 同属 Sakana 演化自改进路线。
- **实测**：`sine_approx` evaluator 可跑通（初始得分 0.1045）；完整演化需 LLM API key。
- 链接：https://github.com/SakanaAI/ShinkaEvolve

### 8. algorithmicsuperintelligence/openevolve（OpenEvolve）⭐7.4k · 2025-05 · Python
- **定位**：**AlphaEvolve 的开源实现**（OpenEvolve）——科学发现/程序演化引擎。
- **RSI 关联**：演化搜索改进算法/程序的工作流。（用户提供 `Slyracoon23/open-evolve` 404；实际仓库为 `codelion/openevolve`，gh 解析重定向至本仓。）
- **实测**：CLI 可跑、`evaluator` 可实例化（combined_score=1.419）；无 key 时 LLM 调用自动 retry。
- 链接：https://github.com/algorithmicsuperintelligence/openevolve

## 阅读提示

- 自参考 ≠ 天然有效：按 P09 的内省阈值观点，**自建模能力不足 → 递归退化**。跑这些框架时建议设置"逐代独立评测"，观测是否出现 improvement degradation。
- 安全提示：自我修改代码的框架不应在无沙箱环境直接部署（与 [03 区](03_基础设施安全与资源.md) 的 Misevolution/红队项目配套阅读）。
