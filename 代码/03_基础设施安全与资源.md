# 03 · 基础设施、安全与资源（Infra / Safety / Resources）

> 这一类的价值不在"又一个自改进算法"，而在**让 RSI 可测量、可复现、可控**：
> - **可测量**：闭环传感器（sentrux）、可复现 AI4AI（OpenRSI）、AGI 基准（recursive-self-improvement-suite）
> - **可控**：红队/治理（ai-redteam）、误演化观测（Misevolution）
> - **可探索**：三大资源地图（awesome-*）

## A. 基础设施 · 让自改进闭环可观测

### 1. sentrux/sentrux ⭐3.3k · 2026-03 · Rust
- **定位**：实时**架构传感器（architectural sensor）**：帮助 AI 智能体闭合反馈回路，实现代码质量的递归自改进。纯 Rust。
- **RSI 关联**：RSI 工程最缺的是"**反馈信号**"（验证问题，见 [P01](../论文/cards/P01_RSI综述_2607.07663.md) 与 CACM 争论）；sentrux 用传感器在部署时提供可信信号，供智能体改进自身代码。
- 链接：https://github.com/sentrux/sentrux

### 2. FrontisAI/OpenRSI ⭐719 · 2026-07 · Python
- **定位**：面向 **AI4AI（用 AI 改进 AI）** 的可执行/可测量/可复现框架；**OpenMLE** 与 **Frontis-MA1** 的载体。
- **RSI 关联**：把 RSI 做成可运行、可出指标的"实验平台"；配套 Awesome 列表（FrontisAI/Awesome-Self-Improving-Agents）。
- 链接：https://github.com/FrontisAI/OpenRSI

### 3. keskival/recursive-self-improvement-suite ⭐55 · Python
- **定位**：**开放端、非模仿性任务套件**——涉及可泛化技能的基准，用于支撑"自举式递归自改进"与无歧义 AGI 评测。
- **RSI 关联**：回答 P10/CACM 争论中的前一半——**怎么独立验证自改进是真改进**（与"写保护 holdout"思想一致）。
- 链接：https://github.com/keskival/recursive-self-improvement-suite

## B. 安全 · 让 RSI 可控

### 4. ShaoShuai0605/Misevolution ⭐98 · 2025-09 · Python
- **定位**：论文《Your Agent May Misevolve: Emergent Risks in Self-evolving LLM Agents》**官方实现**。
- **RSI 关联**：直接研究自进化智能体的**涌现风险（误演化）**——对应本库 [基础知识/03](../基础知识/03_理论边界与安全.md) 的"误演化"风险条目；是"自进化有害行为"的实证/代码证据。
- 链接：https://github.com/ShaoShuai0605/Misevolution

### 5. lihouwenbin/ai-redteam-recursive-self-improvement ⭐35 · Python
- **定位**：领域无关的 **AI 红队框架**，面向 RSI 治理。
- **RSI 关联**：给"开放端 RSI"类系统做红队测试的脚手架——把 P01 风险集中点的讨论落到可执行演练。
- 链接：https://github.com/lihouwenbin/ai-redteam-recursive-self-improvement
