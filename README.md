# RSI 知识库 · Recursive Self-Improvement

> **RSI = Recursive Self-Improvement（递归自我改进）**：一个 AI 系统不仅改进自身，还改进"改进自身的能力"——即自我改进的加速回路（self-improving loop）。

## 一分钟结论

1. **RSI 不是新概念，但 2025–2026 第一次成为工程实践**。思想源头可追溯至 Good (1965) 的"智能爆炸"、Schmidhuber (2003) 的 Gödel Machine、Yudkowsky (2007) 的 Seed AI；如今碎片化的自改进回路已经在部署期（输出精修、技能演化）、训练期（自我奖励、自我博弈）、评估期（自建评判器）、研究过程（AI 科学家）四个层面工程化 [2607.07663](论文/cards/P01_RSI综述_2607.07663.md)。
2. **衡量 RSI 的标尺是"闭环程度"**：人在环内（human-in-the-loop，有界自精修）→ 半闭环 → 全闭环（连评估器/目标一起改，即开放端 RSI）。绝大多数论文仍是前一种；后一种才是安全风险的集中点。
3. **2026 年的标志事件**：OpenAI 在 GPT-5.3-Codex 发布说明中首次明确承认"早期版本的模型对创造自身起到了作用"（instrumental in creating itself）；Anthropic 发表 RSI 专题文章，用"AI 参与 AI 改进的自主度连续谱"来定位这一转变（见 [基础知识](基础知识/01_什么是RSI.md)）。
4. **主要风险争论**：内省阈值（自模型能力不足时递归会退化，[2607.04277](论文/cards/P09_内省阈值_2607.04277.md)）、算力瓶颈（智能爆炸的两个必要条件，[2507.23181](论文/cards/P10_算力瓶颈_2507.23181.md)）、以及"有损自改进 LSI"等质疑。
