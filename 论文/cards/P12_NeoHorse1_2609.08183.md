## 一句话结论

> RSI 需要一个具体机制：AI 系统**观察自身能力 → 把证据转化为下一轮学习**。NeoHorse-1 用"路由 harness"落地了这一定义——异构模型池 + 智能路由记录每一次交互的能力需求/服务档位/结果，把这些记录**结构化转化为训练样例**，经三阶段课程 SFT + 路由引导的 on-policy 蒸馏让模型变强，再让**能力反馈决定下一轮训练混合**，形成 `评估→选择→更新` 闭环——4B 从 58.94→64.87、9B 从 65.60→69.04，4B 后训练模型显著逼近 9B 基线。

## 问题背景

- 多数自改进工作把回路开在**推理期**（自我精修）或**单一模型内**；NeoHorse 主张：真实可扩展的 RSI 需要一个**介质的、多模型的回路**（harness-mediated RSI）。
- 关键未知：真实用户交互 + harness 上下文的轨迹，如何**变成可训练数据**、并反过来指导下一轮学习。

## 方法（核心=闭环的四个环节）

1. **路由 harness（评估→选择）**：异构模型池中按"预测的能力需求"路由每个用户 turn，记录：能力需求、所选服务档位、后续交互。
2. **轨迹→训练数据（数据管线）**：保留交错推理、工具调用与 harness 上下文；经四道闸：精确/近似去重 + 评估污染剔除 → **结构验证** → **六维语义评估** → **子场景级标注（Scene/Goal/Outcome）**。
3. **三阶段课程 SFT + 路由引导 on-policy 蒸馏（更新）**：路由信号把 SFT 组织成三阶段课程；蒸馏阶段教师（更强档位）在**同一课程进程**下监督学生生成的回应。
4. **能力引导分配（闭环回到下一轮）**：评估反馈 → 决定下一轮训练混合——**系统学到什么，塑造它下一轮从什么学**。

## 关键结果

| 规模 | 宏平均（11 基准） | 提升 |
|---|---|---|
| 4B（Qwen3.5-4B 底座） | 58.94 → **64.87** | +5.93 |
| 9B | 65.60 → **69.04** | +3.44 |

- 4B 主要增长点：WorkBuddy +9.79（agent 工作流）、VitaBench +10.50、HumanEval +9.75、QwenClawBench +6.21。
- **关键叙事**：后训练 4B（64.87）显著缩小 vs 9B 基线（65.60）的差距——"能力引导分配"让小模型从混合池中学到接近大模型的执行能力。
- 官方定位：这是反馈驱动原型，"向 harness 中介的跨代 RSI 迈进的第一步"（一代=一轮后训练）。

## 与 RSI 知识库的关系

- **P01 综述"训练期"方法族的工程闭环实例**；比 LADDER [P04]/LSP [P06] 更进一步：不止"自我博弈产生信号"，而是**把 harness 的真实交互日志做成信号源 + 用能力反馈改学习内容**——最接近 RSI"改进改进能力"的工程演示。
- 与 GVU [P02] 的映射：G=异构模型池（路由选择生成者），V=结构验证+六维语义评估+基准，U=课程 SFT+蒸馏——且 **U 的输入由上一轮 V 的反馈决定**（闭环）。
- 与 [P09 内省阈值](P09_内省阈值_2607.04277.md) 形成的张力：NeoHorse 的"能力引导闭环"默认每一轮都在自我提升，但 P09 警告低于阈值会退化——NeoHorse 用**外部 structure（基准+语义评估）而非纯自评**来守门，恰是对抗退化的正确姿势，但多代迭代（不只一代）是否稳，尚未验证。

## 金融映射（预告）

NeoHorse 的闭环结构**可直接移植到量化研究**：
- 路由 harness = 策略池中按市况/资产路由（不用模型，用确定性规则即可）
- 交互记录→训练数据 = 策略执行日志 + 归因
- 能力反馈→下一轮混合 = 按 Sharpe/回撤表现加权下一轮策略采样分布
- 详见 [金融应用区](../金融应用/README.md) 的最小成本复刻方案。

## 解读与批判

- ✅ **优点**：a) 把 RSI 从"论文里的回路"做成"有基准、有权重、可下放的闭环系统"；b) 数据管线工程完整（去重/污染剔除/结构验证/六维评估），是**工程基准线**；c) 开源 Apache-2.0 + ModelScope/HF 双发，4B 模型一张消费级显卡可跑。
- ⚠️ **局限**：a) **只有一代**后训练——"跨代 RSI"是声称的方向而非已验证事实（需要多轮更新→harness→再更新）；b) 能力引导分配可能**把训练分布塌缩到高能力子域**（类似 P08 的自洽≠正确风险）；c) 基座是 Qwen3.5-4B/9B，依赖 Qwen 系生态；d) 11 个基准全是通用 agent/编码/指令任务，**无金融/专业域验证**——专业域复刻需要银行级数据管线。
- 🔎 **金融复刻要点**：复刻其**闭环结构**而非模型本身——用确定性回测当验证器（免费、客观），用 LLM 当生成器，用表现加权当更新器（详见 [金融应用](../金融应用/README.md)）。
